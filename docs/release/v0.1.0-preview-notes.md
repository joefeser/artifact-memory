# Artifact Memory 0.1.0 preview notes

Status: development preview; not signed, published, or released.

The preview assembles the provider-free reference runtime, versioned contracts,
synthetic conformance receipts, bounded context and exchange boundaries,
generated index rebuilds, encrypted backup/isolated restore seams, TraceMap and
WITS adapter fixtures, and explicit authenticity, retention, and authority
limits.

Known release blockers remain tracked by the open umbrella work: first
off-machine custody write and restore evidence, independent v2 exchange,
complete scale/resource baselines, final all-surface privacy/history audit,
owner release-key fingerprint and signed annotated tag, anonymous public-clone
verification, visibility approval, and push-rule restoration.

The repository is a clean Apache-2.0 rewrite informed by Joe Feser's 2010
WhereAreMyFiles project. Historical per-file MIT attribution and the strict
non-migration boundary are documented in
`docs/contracts/v0-lineage-observations.md`; historical SHA-1 and `NONE` values
are never upgraded to Artifact Memory content identity.
