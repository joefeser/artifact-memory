# Artifact Memory 0.1.0 preview notes

Status: development preview; not signed, published, or released.

The preview assembles the provider-free reference runtime, versioned contracts,
synthetic conformance receipts, bounded context and exchange boundaries,
generated index rebuilds, encrypted backup/isolated restore seams, TraceMap and
WITS adapter fixtures, and explicit authenticity, retention, and authority
limits.

The independent v2 exchange and bounded resource baselines are complete. A
sanitized external owner attestation records completion of the first encrypted
off-machine custody write, full-data integrity check, and isolated restore. The
repository validates the attestation shape and privacy boundary but cannot
replay the private operations. Known release blockers remain tracked by
the open umbrella work: final all-surface privacy/history approval, owner
release-key fingerprint and signed annotated tag, explicit visibility
approval, post-visibility anonymous clone verification, and push-rule
restoration.

An exact-commit unsigned preview builder now prepares the source tar,
`SHA256SUMS`, v2 manifest, and machine/human preparation receipts only in an
empty external directory. It grants no signing, tag, publication, visibility,
or deployment authority; final assets must be regenerated from the later
owner-approved release commit.

Preview output is staged, reread, and atomically exposed. Its checksum scope is
explicitly limited to manifest-listed release assets, while the manifest and
receipts remain separately digest-bound evidence metadata.

The repository is a clean Apache-2.0 rewrite informed by Joe Feser's 2010
WhereAreMyFiles project. Historical per-file MIT attribution and the strict
non-migration boundary are documented in
`docs/contracts/v0-lineage-observations.md`; historical SHA-1 and `NONE` values
are never upgraded to Artifact Memory content identity.
