# Initial Roadmap

## Milestone 0.1: Contract foundation

- vocabulary and trust boundaries;
- canonical JSON and identifier rules;
- content object, manifest, and scan receipt schemas;
- artifact, version, endpoint, and observation schemas;
- extension and adapter contracts;
- synthetic cross-platform fixtures.

## Milestone 0.2: Dogfood vault

- reference CLI;
- scan, manifest, verify, and diff;
- logical endpoint resolver;
- generated NDJSON and SQLite projections;
- private-vault bootstrap and context export;
- encrypted backup and isolated restore proof.

## Milestone 0.3: Interoperability preview

- exchange envelope and admission receipts;
- two independent adapters or implementations;
- cross-platform conformance evidence;
- security and privacy audit;
- documentation and public-release readiness.

The issue tracker is authoritative for delivery state. This roadmap describes
sequence, not completion.
