# Minimum extension conformance fixture

This corpus is newly authored synthetic data. It proves only the first v0
extension seam: one unknown optional declaration round-trips opaquely, one
unknown required declaration fails closed, and explicit support admits that
same required declaration without changing it.

The checked machine and human receipts also prove that extension containment
does not replace core fields and grants no executable authority. This corpus
does not define registry, discovery, marketplace, inheritance, remote loading,
or plugin execution behavior.
