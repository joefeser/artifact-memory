# Support scope

Artifact Memory is a development preview with no service-level agreement.
Supported questions and bug reports are limited to public-safe, reproducible
behavior in the versioned schemas, reference CLI, adapters, synthetic fixtures,
and documented conformance commands.

The project does not provide support for storing credentials, recovering owner
keys, operating private vaults on behalf of users, interpreting provider-owned
meaning, granting WITS/HACP task authority, executing received knowledge,
rewriting private history, or recovering data that lacks an independently
verified backup.

Before public launch, support coordination remains owner-controlled. After
launch, public-safe defects may use GitHub Issues. Security reports, private
records, credentials, customer material, raw conversations, vault paths, and
attachments must never be posted to a public issue; follow `SECURITY.md`.

Compatibility follows `docs/release/versioning-and-launch.md`. Pre-1.0 Python
implementation APIs are unstable, while published versioned contracts retain
their documented preservation, rejection, migration, and deprecation rules.
